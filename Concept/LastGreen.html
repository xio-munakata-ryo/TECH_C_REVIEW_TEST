✳ THE LAST SEED — 森の最後の希望
01 / GAME OVERVIEW

森を育てることが、
最強の防衛になる。

枯れゆく世界に、もう一度緑を。

機械の侵略によって荒廃した大地。プレイヤーは森の守り手となり、最後に残された「世界樹の苗木」を守ります。

防衛施設は、ただ敵を倒すだけではありません。敵の進路に森を広げ、地形と自然の力を味方につけることで、戦況そのものを変えていきます。

TDジャンル

Unity開発環境
02 / CORE GAMEPLAY

考えて、育てて、守り抜く。

敵の進行ルートを読み、限られたエネルギーをどこに使うか。準備と判断が勝利の鍵です。

STEP 01⌖

戦場を読む

地形と敵の進路を確認。守る場所と迎撃地点を決める。

STEP 02✳

森を配置する

エネルギーを使い、攻撃・妨害・支援の樹を植える。

STEP 03➤

ウェーブを迎撃

敵の特性に合わせて、配置と能力を組み合わせる。

STEP 04⌁

森を再生する

報酬で森を強化。次の波に備えて戦略を更新する。

03 / DEFENSE UNITS

自然の力を、戦術に変える。

それぞれの樹には得意分野があります。単独の強さより、組み合わせを見つけよう。

✦

光の弾で遠くの敵を狙う基本ユニット。迷ったときに頼れる安定した攻撃力。

04 / THE WORLD

守るたびに、
世界が色づいていく。

戦いの舞台は、灰色の荒野から始まります。ウェーブを乗り越えるごとに苗木は成長し、草花や動物たちが少しずつ帰ってくる。勝利の手応えを、変化する景色でも感じられます。

「森を守ることは、明日を植えること。」
05 / DEVELOPMENT PLAN

まずは、遊べる一本を。

小さく完成させてから面白さを確かめ、段階的に遊びの幅を広げます。

PHASE 01 / PROTOTYPE

防衛の基本を作る

敵の移動、ユニット配置、攻撃、勝敗判定を実装。1ステージを最後まで遊べる状態にする。

PHASE 02 / GAMEPLAY

戦略の選択肢を増やす

ユニットと敵の種類、強化、ウェーブ構成を追加。組み合わせの面白さを調整する。

PHASE 03 / POLISH

森の世界を仕上げる

UI、演出、サウンド、ステージを整え、初めて遊ぶ人にも伝わる体験にする。
